LinBPQPages is a web application to read and compose messages on a LinBPQ
BBS. Born as a sister project to LinFBBPages, it had two goals: to make the
mailbox of the BBS available on the web without exposing the administrative
tools, and to provide a REST API to integrate external services and agents.

Instead of the built-in LinBPQ web, it offers a responsive interface focused
only on messaging: paginated message list and search, reading of private
messages and bulletins with attachments, and browsing and downloading of
decoded 7+ files. It is available in English and Spanish.

How it works: it reads the instance files directly (DIRMES.SYS, Mail/,
linmail.cfg and HTML/7plus/), and its only write is an append to
Mail/Import/mail.in when composing a message. It is written in Go using only
the standard library, with an embedded frontend, and builds in minutes.

The article covers the details, the full API, the security considerations and
the roadmap.
