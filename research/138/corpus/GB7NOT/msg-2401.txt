As you may well know our Pocket Pic TNC Project was featured on Hackaday!
https://hackaday.com/2026/09/25/pi-pico-recreates-the-heathkit-pocket-packet/

Gene N7WDZ also has a nice page on the build.
https://n7wdz.com/project-pocket-pico-tnc.html

In any case we decided it was time to try and produce some firmware for the pocket pico so it could operate on HF as well as HF APRS or NETWORK 105 ax25 Packet.

We have been testing the latest code and it seems to be working pretty well.
Anyone with a pico can test it, you can grab the .uf2 file to flash your
pico with the HF version here:
https://github.com/pfiliberti/pico_tnc/tree/pocketpicohf

Also we have updated the vhf version to correct a possible problem where the pico could possibly hang with the PTT stuck on. If you are operating a pico I would suggest
to get the latest firmware and update it. It can be found here: 
https://github.com/pfiliberti/pico_tnc
