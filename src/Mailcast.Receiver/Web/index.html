      What's in it
      
Your callsign and the date, the receiver's version, the web SDR it listens through and its locator (or just "sc" for a sound card), and for each slot it listened to: the speed, the frames heard, the tone's signal to noise and offset, and the radio path as measured. For example:

Input level

    

    
Peaks between -18 and -9 dBFS are best.

    
Check the level while a slot is on. Between slots there is only band noise, so a lower reading then is normal.
