Listen for a station
 a station nobody advertises yet
      
Give the slots and frequency of a station and this receiver listens at them like it does for an advert heard on air (the same limits apply, and only if it can tune there). Once the station's own signed directory is heard its own timetable is used and the entry goes; an entry never heard in 7 days goes too. Minute and every are that station's slots. The frequency is the centre of its signal, not the dial; the receiver works out the dial.

Minute past the hour and every (minutes) are that station's slots. Daylight only needs a locator (from 120 minutes after sunrise to 30 before sunset there, as a head end would say); with no locator it listens at every slot.

      

    

  


  

    

      
Keys
 who may sign the directories this receiver uses
      
A directory is used only when a key below signed it. One with no signature is not used, and nor is one signed by a key not listed. A station's key is learnt the first time its signed directory is heard; forget a learnt key if it should not be trusted, and it is learnt again the next time that station's directory is heard. Keys from the config file (trustedKeys) are changed in the config file.

Sharing pieces
 objects and pieces other programs can read, and hand in
      
This receiver keeps the pieces of every object it hears, of any kind, to pass on. Other receivers and programs can read them from this page's address (/api/objects; API reference); nothing is needed to read. To hand pieces in, a program needs the key below. Without a page password, anyone on your network can see this key and change it. Pieces handed in are counted apart from the ones heard on air, and never count for a slot or for the station heard most.

Where it bounced
 a globe of today's paths from the stations heard
      
Each slot's path from the station heard to this receiver, up to the virtual height measured and back down, on a true-size round Earth with nothing exaggerated. The bright points are where it turned round, and a ring marks where a two hop signal touched the ground. Where each bounce sits along the path is an estimate: halfway for one hop, a quarter and three quarters for two. Drag to turn, scroll or use + and - to zoom.

      

        
        

      

      

        
        
        
        
        
      

      

    

  


  

    
What was heard

    
The last few slots, burst by burst: each frame's piece number, whether it was new, already held or completed what it belongs to, and whether its CRC was good. For checking coverage and for debugging. Kept in memory only, not written to disk, so it starts empty again after a restart.

Settings

    

      
      
      
      
The dial is set by "dialKHz" in receiver.json; the signal itself stays at the audio centre. An SDR or a web SDR needs no change here.

      

        
        
Where your radio is, as a 4 or 6 character Maidenhead locator: "locator" in receiver.json. It names the radio path's hops and where they come down, and goes in the daily report. A web SDR says where it is itself.
